# GPU queue scripts

These scripts record the order in which the experiments ran on one 8 GB GPU, as the plan changed (each change is in `LOG.md`;
start and end times are in `results/queue.log`). They are kept for the record. To reproduce a result, run its script in `src/`
directly, as given at the top of each script. Run from here, each queue script changes to the repository root first.
